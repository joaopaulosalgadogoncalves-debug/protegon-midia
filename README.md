# protegon-midia

Artes públicas das redes sociais da PROTEGON, já aprovadas para publicação.
Os links "raw" destes arquivos são usados pelo Metricool para agendar os posts.

- `modulos/<modulo>/`: carrossel do Instagram (`ig_01` a `ig_05`) e card do LinkedIn (`li_post`).
- `serie/controle.csv`: ordem e situação da série de módulos (não repetir até terminar).

Regra: aqui entram somente imagens que serão publicadas. Nunca documentos internos, dados de clientes ou capturas de tela com dados reais.
